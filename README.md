# 🤖 AI Generation Platform — Through the Eras

An interactive AI knowledge explorer that combines the history of Artificial Intelligence with a lightweight Retrieval-Augmented Generation (RAG) inspired chatbot experience.

## 🚀 Overview

AI Generation Platform — Through the Eras is a browser-based educational platform designed to help users explore the evolution of AI technologies while interacting with an intelligent knowledge retrieval system.

The platform combines historical AI timelines, keyword-grounded knowledge retrieval, optional LLM integration, and user feedback mechanisms to create an engaging AI learning experience.

---

## ✨ Features

### 📚 AI Through the Eras Timeline

Explore the major milestones in the evolution of Artificial Intelligence, from early rule-based systems to modern Generative AI and Large Language Models.

### 🔍 Local RAG-Style Knowledge Retrieval

Uses a structured AI/ML knowledge base and keyword matching system to retrieve relevant information without requiring cloud-based AI services.

### 🧠 Intelligent Query Classification

Includes a lightweight in-browser pattern model that:

* Identifies user intent
* Matches topics to relevant AI concepts
* Improves response relevance

### 🤖 Optional LLM Integration

Supports OpenAI-compatible APIs for enhanced conversational responses when a valid API key is provided.

### 💬 Interactive Chat Experience

Users can ask questions related to:

* Artificial Intelligence
* Machine Learning
* Deep Learning
* Neural Networks
* Generative AI
* Computer Vision
* Natural Language Processing
* Data Science

### 👍 Feedback Learning System

Simple "Good" and "Wrong" feedback buttons allow users to provide response quality feedback, helping improve future retrieval logic.
